# Bedrock Wither — Product Evidence

Git-tracked product evidence is intentionally small.

Store here:
- source/build identity manifests;
- GameTest result summaries;
- Tank comparison manifests;
- hashes and bounded receipts;
- scenario definitions that are safe to publish.

Do not store here:
- raw worlds;
- credentials;
- huge logs;
- videos/image dumps;
- full third-party JAR/source trees;
- private runtime captures.

Those remain in the existing bounded runtime/CAS workflow, with this directory retaining locators/hashes when needed.
