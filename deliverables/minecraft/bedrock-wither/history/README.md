# Bedrock Wither — Product History

This directory preserves the history of **our implementation**, not upstream Bedrock or third-party projects.

Files:
- [TIMELINE.md](TIMELINE.md): concise chronological milestones.
- [DECISIONS.md](DECISIONS.md): durable architecture/product decisions.
- [failure-repair/](failure-repair/README.md): defects, failed assumptions, repairs and reusable lessons.

Research history for third-party MODs stays in `departments/minecraft/mods/*`.

Rules:
- do not rewrite an old decision to make it look correct in hindsight;
- add a superseding decision and link both;
- preserve failed experiments as FAIL/UNKNOWN;
- when a failure yields a generally reusable technique, stage it back through the Hub's normal evidence/review path rather than declaring it canonical here.
