# 弾幕下書きプレビュー

ユーザーが承認したJavaFX 3Dの最小設計を実装する。Minecraftを再起動せず、
弾幕の形・間隔・速度・時間変化を調整するための下書きである。

- 純Javaの等速直線モデルとJavaFX画面を分離する。1単位=1block、20tick/秒。
- 発射点(0,2,0)、基準方向+Z、+Y上向き。扇状、全周、回転全周連射。
- 弾数、速度(block/tick)、間隔(tick)、扇角度、回転(deg/秒)、仰角、寿命、期間を編集。
- 再生/停止、最初から、1tick送り、時間スライダー。変更は現在時刻へ即反映。
- 格子、発射点、プレイヤー目印、球の弾。上面/側面/自由視点。
- 平坦なJSON v1を保存/読込。未知項目・型・非有限値・過大入力を拒否する。
- 最大同時弾数3,000、最大60秒。上限では弾を黙って省略せず入力を拒否。
- Windows x64、JDK17以上、OpenJFX21.0.9のみ追加。jarはGitに含めない。
- Minecraft本体・正式ワールド・Ver1.00を変更しない。MOD取り込みは次段階。
- 既存DanmakuShootの重力・ばらつき・衝突・damageの再現は今回の範囲外。

検証: 手計算の位置/発射間隔/寿命/巻き戻し/JSON拒否を純Javaで確認する。
JavaFXは実起動し、同じ操作経路を使う有限smokeと画面を確認する。
既存リポ回帰はCIで確認し、新規Draftで公開する。
