# 基礎AI — Foundations

**状態:** 分類のみ。比較実験は NOT_RUN。

状態機械（FSM）、Behavior Tree、GOAP、HTN、Utility AI、A*/Dijkstra等の探索、Blackboard、Sensor、ターゲット選択と行動優先度を研究する。

研究では **戦略・行動決定・移動制御** を分け、処理コスト、動的環境への再計画、失敗復帰、再現性を比較する。各方式は用途により併存でき、全部を単一の標準AIに置き換えない。

既存の応用例：[Minecraft Vanilla AI研究](../../minecraft/vanilla-ai/README.md)。Minecraft固有の証拠や実装は元部門で保持する。
