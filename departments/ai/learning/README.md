# 学習・適応・進化AI

**状態:** 研究対象の分類のみ。学習モデルや試験結果は未作成。

対象を混同しない：
- **ルールベース適応:** ダメージ種別・失敗回数を蓄積し、耐性や行動を変更。
- **強化学習:** 観測・行動・報酬・方策・探索と学習費用。
- **進化アルゴリズム:** 適応度、選択、突然変異、交叉、多様性。
- **継続/転移学習:** 記憶の保持、忘却、負の転移、再学習コスト。

[Scape and Run: Parasitesの原作Bytecode](../../minecraft/mods/scape-and-run-parasites/COMBAT-AI-BYTECODE-2026-10-11.md)には攻撃への適応と群体継承のコード経路がある。ただし**カウンタによる耐性学習はニューラルネットワークや遺伝的進化ではない**。これらを新たに試作するなら別の独立研究として検証する。
