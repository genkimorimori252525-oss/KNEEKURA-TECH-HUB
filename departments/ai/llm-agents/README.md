# LLM・自律エージェント

**状態:** 領域定義のみ。AI議会・自律実装基盤・モデル学習を作ったわけではない。

言語モデル、推論、学習、量子化、ローカル/クラウドモデル、ツール実行、長期記憶、複数エージェントの役割分担と検証を扱う。

重点調査：API前提・非API方式の両方、CPU/GPU/VRAM・レイテンシ・コスト、失敗時の再試行、ツール権限とプロンプトインジェクション対策、人間の承認が必要な操作。LLMが複数いるだけで精度が上がるという前提は置かない。

[Minecraft MOD-AI](../../minecraft/mod-ai/README.md)は既存のMOD制作ツール群。汎用LLM部門へ移動せず、技術的に必要な部分だけ相互参照する。
