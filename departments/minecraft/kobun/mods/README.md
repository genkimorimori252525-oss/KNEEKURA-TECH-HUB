# 古文 MOD workspaces

太古の Minecraft MOD 個別解析は、このディレクトリ配下へ置く。

```text
kobun/mods/<target-slug>/
```

各 target は [../TARGET-TEMPLATE.md](../TARGET-TEMPLATE.md) を入口にし、
[../ANALYSIS-SPEC.md](../ANALYSIS-SPEC.md) の ORIGINAL-first 規則へ従う。

この場所の target を現代 `departments/minecraft/mods/` へ重複登録しない。
現代へ持ち帰る成果は target 内の `MODERN-EXTRACTION.md` に記録し、
必要になった時だけ別の現代実装計画へ接続する。
