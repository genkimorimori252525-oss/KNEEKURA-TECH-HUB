## Intake rules

- 典型候補は Minecraft 1.7.10 以前。
- ただし version cutoff は絶対ではなく、API/loader/mapping 世代差で判断する。
- 各 target は最低1本の ORIGINAL track を持つ。
- later port/fork/remake は DESCENDANT として別記する。
- 1.20.1 への持ち帰りは MODERN-EXTRACTION で行い、ORIGINAL の実装事実と混ぜない。
- raw JAR / full decompile / third-party assets は通常 Git に置かない。
- NOT_PINNED / UNKNOWN / UNAVAILABLE は正当な状態。
