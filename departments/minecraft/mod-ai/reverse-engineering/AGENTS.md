# Optional reverse-engineering scope

This file applies only inside this optional shelf. It does not impose a startup
step or a checklist on other TECH HUB tasks.

- Enter only when the current task actually requires binary/bytecode analysis,
  an alternate decompilation, or an explicit request for CFR/Vineflower/REA.
- Do not read this folder, run catalog/help/doctor, inspect versions, install
  packages, or check readiness during unrelated coding or research tasks.
- Prefer already available source and recorded evidence. Choose one suitable
  tool; do not automatically run both decompilers or every REA provider.
- Keep the existing Vineflower CAS/profile transform as the authoritative
  indexed MOD-AI path. The standalone comparison runner does not replace it.
- Installation is separate and explicit: `toolkit.py install TOOL`. Missing or
  corrupt tools fail without auto-installation, repair, upgrade or fallback.
- Do not register this shelf in root AGENTS, global skills, MCP configuration,
  Core startup, task prepare/capabilities, or common dependency manifests.
- Read README.md only after choosing this shelf. Detailed upstream REA manuals
  should be read only for the selected operation, not copied into every prompt.
- Preserve original inputs and old evidence. Never commit `.local`, binaries,
  full decompiled trees, installed packages, user paths or credentials.
- Decompilation output is a derived candidate, not original source, complete
  coverage, or runtime equivalence. Keep these distinctions in reports.
- REA commands can execute targets or access networks/devices. An explicit
  shelf invocation is not blanket authority for those actions or a sandbox.
