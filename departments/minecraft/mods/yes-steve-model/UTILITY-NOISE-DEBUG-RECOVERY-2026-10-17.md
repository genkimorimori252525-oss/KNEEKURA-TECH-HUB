## Reuse and limits

Keep diagnostic queries separate from simulation-state queries: their useful effect is debug output, not their null return. Preserve typed context guards and short-circuit order when reusing these contracts. Perlin seed conversion and native call signature are recoverable Java facts; the native noise algorithm is not established by this document. Source names help navigation but do not globally prove source equality.
