## Avoid these semantic substitutions

1. **Readiness is not visibility.** Model-present excludes some loaded fallback states; texture ID presence is not GPU success. Use [model readiness](MODEL-READINESS-SCOPE-RECOVERY-2026-10-17.md) and [texture lifetime](TEXTURE-HOLDER-LIFETIME-RECOVERY-2026-10-17.md).
2. **Container restrictions are not immutable poses.** Unmodifiable lists can contain mutable bones or wrap retained arrays. A locator's final bone omits reverse-pivot and its all-zero scale does not enter the returned ancestor flag. Use [locator preparation](LOCATOR-MATRIX-PREPARATION-RECOVERY-2026-10-17.md).
3. **A cancelled original draw is not a successful replacement draw.** Player, ordinary-arm, provider-arm and dispatcher paths cancel/suppress at different stages. A void replacement may return without drawing. Use [arm events](ARM-REPLACEMENT-EVENTS-RECOVERY-2026-10-17.md) and [dispatcher routes](DISPATCHER-RENDER-REPLACEMENT-RECOVERY-2026-10-17.md).
4. **An entry's guards do not cover another overload.** Dispatcher invokes animatable overloads directly, bypassing concrete entity-entry checks. Do not copy one path's invisibility/readiness assumptions to all callers.
5. **Preview cleanup is not a transaction.** Flags, camera, lighting, rotations and equipment have separate mutation/restoration order. Observed equipment-suppression callers use FakePlayer; do not claim real inventory loss from the helper in isolation. Use [preview state](GUI-PREVIEW-STATE-RECOVERY-2026-10-17.md).
6. **External adapters need their actual branch.** Installed/default/real branches can differ in types, side effects and initialization time. Choose only relevant adapter evidence; do not install or probe all optional tools/mods. Shader ID packing is signed Java arithmetic, not automatically unsigned lanes. Use [shader/buffer adapters](SHADER-BUFFER-ADAPTERS-RECOVERY-2026-10-17.md).
7. **A callback argument is not necessarily the displayed state.** Terminal sync can reset total before notifying, while UI consumers poll IDLE/queue state separately. Inspect [actual consumers](SYNC-STATE-UI-CONSUMERS-RECOVERY-2026-10-17.md) before calling it a UI bug.
8. **A copy/abort method name does not promise deep ownership or completion.** Respawn shallow transfer, weak listeners and native abort request have explicit boundaries. Use [session bridges](CLIENT-SESSION-SKIN-EVENTS-RECOVERY-2026-10-17.md) and the state/listener dossier.

## Verify only the work you use

- Ordinary navigation reads the prebuilt compact locator. --check-selected checks returned-file hashes only; it does not prove global freshness or new-file coverage.
- For evidence work, run the relevant cohort auditor with the exact JAR and pinned source. For a substantive connected batch, choose its fixed manifest; do not rerun unrelated whole-repository CI after every edit.
- Frozen checkpoints: pipeline17, state/query10, controller9, optional integration14, attachment/render9, render-lifecycle8, client-session5, sound-lifecycle5, event-transition9. They are separate historical manifests, not a sum of recovered methods or an automatic all-tests command.
- The [client-session5 receipt](CLIENT-SESSION-CHECKPOINT-2026-10-17.json) passed in0.751seconds. It joins three new cohorts with two adjacent earlier anchors;0 overlapping snapshots is not independent corroboration.
- Vineflower is a second structural view; javap/exact operands remain the anchor. JDK-only regex/arithmetic models test only the modeled library/language contract. No target/native/GPU run has been claimed.
- Original names, whole source/artifact equivalence, external provider behavior, actual injection and independently reviewed semantics remain separate claims. Preserve conditional findings; do not patch a presumed bug merely because an isolated branch looks unusual.
