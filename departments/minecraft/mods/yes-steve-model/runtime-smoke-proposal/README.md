# YSM 実動作検証の限定提案

状態：自作ハーネスの静的レビュー・偽入力テスト完了。**実行の承認待ち。実物の起動は未実施。**

ここは研究ブランチ上のレビュー資料です。ワークフローは `.yml.txt` として保存し、Actions の登録先には置いていません。保存だけでは実行されません。

## 何を確認するか

GitHub の標準ホスト型 Ubuntu ランナーで、Forge だけの専用サーバーを先に起動・停止し、成功した場合に同じ実行環境へ原本 YSM 2.6.5 を追加して起動・停止します。Java 17、Forge 47.4.0、Minecraft 1.20.1 と原本のハッシュを固定します。

これは実起動の最初の確認です。成功しても、描画、クライアント動作、JNI 登録の全件成功、ワーカー完了、アセットの全件解読が証明されたことにはしません。既存の静的解析・隔離エミュレーションの証拠とは別に記録します。

## 実行する場合の変更と影響

- main に保存するのは `.github/workflows/ysm-runtime-smoke.yml`、`tools/ci/ysm_runtime_smoke.py`、`tools/ci/ysm_runtime_smoke.lock.json` の3ファイルだけ。研究ブランチ全体はマージしません。
- `[skip ci]` 付きの限定コミット後、手動実行を1回行います。直前の main・既存ワークフロー・公開状態を再確認し、変更や権限拒否があれば停止します。
- 標準ホスト型ランナーのみ使用します。自宅PC、セルフホスト型ランナー、有料エージェントは使いません。公開リポジトリの標準ランナー無料枠を利用し、キャッシュ・成果物アップロードは行いません。
- 公式 Forge インストーラーの準備段階には通常の外向き通信があります。原本 YSM と認証情報は渡しません。接続先をファイアウォールで限定した構成ではありません。
- 実際の Forge／YSM 起動は通信なし・非root・読み取り専用の実行環境です。新規の一時ゲーム領域だけを使い、原本 native コードと同梱アセットの通常利用を含みます。
- Minecraft の [EULA](https://www.minecraft.net/ja-jp/eula) への同意後に、一時サーバーの `eula=true` を設定します。まだ設定・同意は行っていません。
- 全体25分、各起動180秒・安定確認20秒・停止30秒の上限。失敗時に隔離を弱めたり自宅PCへ移したりしません。
- 公開 Actions ログには許可した状態・時間・ハッシュ等だけを出します。原本、アセット、ワールド、生ログは公開しません。
