## Performance assessment (inference, NOT benchmark)
Stacked height potentially increases generation work, section storage, light and packet work per XZ column; conventional horizontal chunk loading means remote bands may be generated/loaded even if player never enters them. CustomChunks implementation must be inspected to resolve this; empty sections compress, client culling and heterogeneous generators mean no valid fixed 3x multiplier. Portal/loop rendering may add views near the ends; lower view distance/detail or disable loop for comparison. Default trim is a real exposed option, but memory savings not measured. Entity scanning is a small/simple per-entity check, potential scaling issue at high counts, not evidence of actual lag. Fluid crossing may add work; Planeshift behavior and fallback semantics need separate tests. Public CustomChunks description https://www.curseforge.com/minecraft/mc-mods/customchunks confirms author intent of band-specific generators only. Dependencies absent from supplied JAR; no measured FPS/MSPT/RAM or disk cost.
