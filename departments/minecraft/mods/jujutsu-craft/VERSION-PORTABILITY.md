## Portability classes

### High conceptual portability

- centralized defense/counter policy
- shared domain lifecycle
- per-source adaptation ledger
- persistent field actors
- tag-driven ability eligibility
- shared attack resolver

### Medium implementation portability

- Player capability schema
- PlayerAnimator/Gecko animation split
- MCreator-generated Procedure graph
- entity-based persistent technique fields

### Low literal copyability

- exact generated procedure code
- copyrighted assets/models/textures/animations
- implementation-specific damage source string keys
- All Rights Reserved source/assets
