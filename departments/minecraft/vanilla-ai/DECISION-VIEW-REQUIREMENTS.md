# Decision view requirements from exact ANCHOR research

Source: the approved Entity Decision Observatory plan and [ANCHOR bytecode ledger](ANCHOR-BYTECODE-LEDGER-2026-10-03.json). This file freezes only source-proven observation interfaces; it does not claim implementation/native acceptance.

## Snapshot and burst capabilities

| Channel | Exact source | Semantics and limits |
| --- | --- | --- |
| Goal scheduler | Mob's two selectors; available WrappedGoal getters | Registered/priority/flags/running sampled state; no replayed eligibility or invented inactive reason |
| Brain | Registered memory map, active activities, running behavior getters | Preserve registered-empty versus unregistered; bounded typed values; no arbitrary object traversal |
| Navigation | Current Path and nodes/progress/target/reachability | Declared route, not continuous actual motion or search frontier |
| Base controls | Actual Move/Look/Jump controller identities and proven readable fields | Base cached fields are not a custom controller's full target/state |
| Path-search burst | Original PathFinder search before evaluator cleanup | Exact search ID, bounded actual nodes/scores/flags; no second search or search-budget mutation |
| Ground terrain query | Static ground classifier plus type-default/effective getter | Observer-queried field, distinct from actual evaluated-node cost; refuse unavailable chunks |
| Custom/MOD state | Proven per-owner fields/callbacks | Namespaced phase/head/formation/custom-flight facts; unsupported state stays NOT_EXPOSED |

Snapshot lanes retain at the existing bounded selected-subject cadence. Deep channels are explicitly armed with exact subject/run/process/Arena identity and tick/node/byte budgets, then stop. Record capture truncation and observer risk/cost; do not claim an unmeasured effect is absent.

## Common contract

- Optional INPUT→STATE→CANDIDATE→EVALUATION→SELECTION→EXECUTION→RESULT stages.
- Machine-readable direct/sampled/instrumented/derived/not-exposed/not-captured/unknown statuses.
- Exact source observation references for facts and timeline events.
- Sampled start/stop interval is derived temporal association unless a direct callback establishes more.
- Exact UUID and full generation fence; no stitching across run/process/Arena or changed selection.
- Class presence, static body provenance, hook installation and actual runtime availability are separate capabilities.

Level 0 remains a compact identity/capability/state summary. Typed bounded drill-down adds scheduler/memory/path/control/terrain detail, then orthographic/isometric views and optional live overlay. Free text is not execution authority.

## Presentation acceptance

Keep actual Mob/projectile samples distinct from navigation declarations. Teleport, source gaps and identity boundaries break lines. Missing deep capture remains `NOT_CAPTURED`, not reconstructed thought.

Path field categories require text/numeric/pattern inspection as well as color. Every displayed regional cell declares whether it was merely queried or actually retained from an original search. No inferred cause from a nearby goal/path/motion event.

Phantom/Ghast/custom flight cannot receive invented A* layers. Twilight Forest Hydra heads, Snow Queen phases, Knight Phantom group formation and Ur-Ghast custom flight need separate adapter semantics. The generic fallback must remain useful without those private adapters.

No gameplay objects for drawing, no hidden default-ON overlay, no raw-frame contamination. Native/client and observer-effect acceptance is required for implemented runtime consumers; unit/compile success alone is insufficient.
