# 軽量化 MOD workspaces

性能改善を主目的とする現代MODの個別解析はここへ置く。

```text
optimization/mods/<target-slug>/
```

[../ANALYSIS-SPEC.md](../ANALYSIS-SPEC.md) と
[../BENCHMARK-SPEC.md](../BENCHMARK-SPEC.md) に従う。

通常content MODで見つかった軽量化技術はtargetをここへ複製せず、
[../catalog/TECHNIQUES.md](../catalog/TECHNIQUES.md) から元解析へ参照する。
