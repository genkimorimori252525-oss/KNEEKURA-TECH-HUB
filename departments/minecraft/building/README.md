# 建築（Minecraft Building）

ジャンル **建築** は、自然言語による構造物の設計、ブロック配置データ生成、見え方の検査、地形との関係、そして安全なワールド反映を扱う独立した研究棚です。Mob AI・MOD制作・水槽観測の既存区画は移動しません。

## 登録技術

- [mcbuild](mcbuild/README.md) — **OPTIONAL LOCAL BRIDGE / 実機未検証**。LLM → Blueprint DSL → Voxel Grid → 複数視点レンダリング → 視覚モデルによる見直し → `.schem`。ソースは固定コミットでオンデマンド取得。直接的なゲーム内配置は現段階では対象外。

## バージョン非依存の建築成果物

建築エンジン本体は現行版のまま利用し、完成した構造を **ブロックID/状態 + 相対XYZ座標 + 寸法・基準点** として保持する。ターゲットごとにブロック互換性を検査し、必要なら置換ルールを明示してSchematicを生成する。Minecraft 1.20.1 + Forgeは最初の出力先であり、**建築を計算するエンジンのバージョンを1.20.1に固定する理由ではない**。

現行mcbuildは **Sponge Schematic v3 / DataVersion 3953（Minecraft 1.21）** を出力する。NeoForge MODの対象であるMinecraft **1.21.1のDataVersionは3955** と区別する。一方1.20.1向けのWorldEdit 7.2.15では通常 **v2** 形式が必要。したがって **v3をそのまま1.20.1に読み込めるとはしない**。将来の対象別エクスポータには形式変換と実ブロック定義の適合検査を設ける（現PRでは未実装）。

計画・監査は [mcbuildの軽量監査](mcbuild/AUDIT-2026-11-14.md) と [移植計画](mcbuild/PLAN-2026-11-14-CROSS-VERSION.md) を参照。未実装の変換を対応済みとは扱わない。

## 運用原則

- **FRONTIER と ANCHOR の区別**：mcbuild upstream のゲーム内MODは NeoForge 1.21.1。Tech Hub の適応基準は Forge 1.20.1。混同・自動移植・動作済みの扱いは禁止。
- **設計と実行を分離**：3Dプレビューだけで建築品質やワールドへの安全な配置が保証されたとは主張しない。設計図の形式、ブロック状態、衝突、置換対象、ワールドのバックアップを別途確認。
- **外部ソースは必要時のみ**：通常のKnowledge Core、Minecraft MOD-AI、LABの検索・テストで mcbuild、uv、OpenRouter、ゲームクライアントを起動しない。
- **研究の出典を固定**：実行前に pinned commit とクリーン状態を確認。生成実験の出力は `departments/minecraft/local-artifacts/` に隔離し、証拠として必要なメタデータのみ選別して記録。
- **品質をスコアひとつに潰さない**：構造的な正しさ（配置・寸法・向き）と審美的な判断（外観・独創性・環境調和）を分ける。反復回数は品質の代用品ではない。
